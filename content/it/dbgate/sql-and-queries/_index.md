Interroga i tuoi dati nel modo che preferisci. Scrivi SQL direttamente in un editor completo con formattazione, completamento del codice e risultati modificabili, oppure costruisci le query visivamente con il query designer - senza bisogno di conoscere SQL. I diagrammi ER completano il quadro mostrando come le tabelle sono correlate tra loro, così puoi comprendere il database prima di interrogarlo.

* [Editor SQL](sql-editor) - esegui script, formatta e completa SQL, modifica i risultati delle query
* [Query designer](query-designer) - costruisci SQL visivamente, senza scrivere codice
* [Diagrammi ER](er-diagrams) - visualizza le relazioni tra tabelle e la struttura del database
