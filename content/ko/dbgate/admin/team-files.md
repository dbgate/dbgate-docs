팀 파일은 DbGate 내부 저장소에 저장되는 SQL, 다이어그램 또는 기타 파일입니다. 데스크톱 DbGate는 파일을 사용자 폴더에 저장하며, Team 에디션에서도 같은 방식으로(docker 볼륨에) 파일을 저장할 수 있습니다. 하지만 더 적절한 방법은 파일을 스토리지 데이터베이스에 저장하는 것으로, 이 경우 DbGate 컨테이너를 다시 생성해도 파일이 사라지지 않습니다.

- 디스크 파일
    - 디스크 또는 docker 볼륨에 저장되는 파일
    - docker 볼륨을 명시적으로 정의하지 않으면(예: docker-compose.yaml에서), 컨테이너를 다시 생성할 때 파일도 다시 생성됩니다.
- 팀 파일
    - 스토리지 데이터베이스에 저장되는 파일
    - docker 볼륨을 정의하지 않아도 컨테이너를 다시 생성할 때 사라지지 않습니다
    - 사용자와 역할에 대해 세분화된 접근 권한을 정의할 수 있습니다

## SQL 파일을 팀 파일로 저장
SQL 파일을 저장할 때 "Save to team folder" 체크박스를 선택하기만 하면 됩니다. 해당 파일은 팀 파일로 저장됩니다.
