DbGate Central は、プライベートネットワーク内で実行する小さなアウトバウンドエージェント経由でトラフィックをルーティングすることにより、プライベートネットワーク上にある oData および GraphQL API に接続できます。Shopify および OpenAPI 接続はプロキシできません。

## プロキシの設定

1. **設定**タブを開き、*接続プロキシ*の下に**プロキシ**を作成します。生成されたトークンをコピーします。
2. プロキシが処理できる oData/GraphQL 接続にチェックを入れます。変更するたびにトークンが再生成されるため、選択を変更した後はエージェントを再起動してください。
3. プライベートネットワーク内でエージェントを実行します。
   ```sh
   npx dbgate-central-proxy --token <token>
   ```
   エージェントはアウトバウンド接続のみを行います。ネットワークへのインバウンドアクセスは不要です。
4. エージェントが実行され接続されると、プロキシ対象の接続へのリクエストはエージェント経由でルーティングされます。プロキシが接続されていない場合、DbGate Central は直接取得する動作にフォールバックします。

同じルーティングは [MCP サーバー](../mcp-server) にも適用されます。MCP ツールがプロキシ対象の接続を読み取る際、そのリクエストは同じプロキシを経由します。
