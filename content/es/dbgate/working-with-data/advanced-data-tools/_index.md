DbGate ofrece varias herramientas de datos avanzadas adecuadas para escenarios específicos:

- [Archivos de datos](archives) - datos de tablas almacenados en carpetas (en formato NDJSON) en tu equipo local. Puedes explorar y editar estos datos de forma similar a como exploras las tablas de una base de datos
- [Data deployer](data-deployer) - compara y sincroniza visualmente los datos entre un archivo de datos y una base de datos real
- [Data replicator](data-replicator) - replica tus datos desde un archivo de datos a una base de datos, adecuado para ejecutarse desde la aplicación DbGate o desde la línea de comandos
