Vá além da interface gráfica e coloque o DbGate para trabalhar em suas próprias ferramentas e pipelines. Automatize exportações, importações e implantações com JavaScript executado no aplicativo ou na linha de comando, consulte endpoints GraphQL/OData/OpenAPI como se fossem bancos de dados e estenda o DbGate com seus próprios plugins para drivers de bancos de dados ou formatos de arquivo. Esta seção também documenta a API de scripting e o SQL front matter usado pela base de conhecimento.

* [Conexões de API](api-connections) - navegue e consulte endpoints GraphQL, OData e OpenAPI REST
* [Documentação da API](apidoc) - referência da API de scripting do DbGate
* [Desenvolvimento de plugins](plugin-development) - crie plugins para mecanismos de bancos de dados e formatos de arquivo
* [Scripting](scripting) - automatize tarefas com JavaScript, no aplicativo ou na linha de comando
* [SQL Front Matter](sql-front-matter) - anote scripts SQL para a base de conhecimento e gráficos
