DbGate は、DDL を手書きすることなく、GUI からデータベース構造を作成・変更できます。テーブルの構造エディターはコンテキストメニュー（「Edit table」）から開けます。また、データベースのコンテキストメニューから新しいテーブルを作成できます。

![Table structure editor](https://media.dbgate.io/img/table-structure-editor-light.png)

## テーブルの編集

* **列とデータ型** - 新規または既存のテーブルに対して、列、データ型、NULL 許容、既定値を定義します。
* **キーとインデックス** - 主キー、外部キー、インデックスを管理します。
* **エンジン固有のプロパティ** - MySQL のテーブルエンジンなど、データベース固有のオプションを設定します。

## SQL プレビューと安全な変更

* **SQL プレビュー** - 保存される前に、DbGate が生成された SQL を表示するので、内容を確認できます。
* **テーブル再作成の警告** - 変更にテーブルの再作成が必要な場合（一部のデータベースの制限による）、DbGate は警告を表示し、生成されたスクリプトを事前に確認できるようにします。

## その他のデータベースオブジェクト

ビュー、ストアドプロシージャ、関数といった他のオブジェクトも作成・削除・変更でき、オブジェクトツリーからテーブル、ビュー、プロシージャ、関数、MongoDB のコレクションを参照できます。
