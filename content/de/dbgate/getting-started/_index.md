Bringen Sie DbGate zum Laufen und verbinden Sie sich mit Ihrer ersten Datenbank. DbGate läuft als Desktop-Anwendung unter Windows, macOS und Linux oder als Webanwendung in Docker, NPM, AWS und Azure - Sie können es also so installieren, wie es zu Ihrer Umgebung passt. Nach der Installation erstellen Sie eine Verbindung, indem Sie Ihre Serverdaten eingeben (optional mit SSH-Tunnel und SSL), und DbGate öffnet die Datenbank zum Durchsuchen und Abfragen.

* [Installation](installation) - installieren Sie die Desktop-App oder stellen Sie die Web-Version bereit (Docker, NPM, AWS, Azure)
* [Verbindung](connection) - fügen Sie eine Verbindung hinzu, wählen Sie einen Passwortmodus und konfigurieren Sie SSH-Tunnel und SSL
