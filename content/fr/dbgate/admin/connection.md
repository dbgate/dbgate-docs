## Onglet Connexions
Configurez les connexions disponibles dans DbGate. Les connexions doivent être associées à des utilisateurs ou à des rôles pour être disponibles.

![Administration des connexions - DbGate](https://media.dbgate.io/img/connection-administration-light.png)

## Accès direct à la base de données de stockage
L'utilisateur administrateur a également accès à la base de données de stockage interne, ce qui permet d'effectuer des opérations directement sur la base de données (par ex. exports/imports d'utilisateurs, etc.). Cette permission peut également être accordée à tout autre utilisateur, permission « Interal storage »
