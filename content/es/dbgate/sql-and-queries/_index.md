Consulta tus datos de la forma que mejor te convenga. Escribe SQL directamente en un editor completo con formato, autocompletado de código y resultados editables, o crea consultas visualmente con el diseñador de consultas, sin necesidad de conocer SQL. Los diagramas ER completan el conjunto mostrando cómo se relacionan tus tablas, de modo que puedas comprender la base de datos antes de consultarla.

* [Editor SQL](sql-editor) - ejecuta scripts, da formato y completa SQL, edita los resultados de las consultas
* [Diseñador de consultas](query-designer) - crea SQL visualmente, sin escribir código
* [Diagramas ER](er-diagrams) - visualiza las relaciones entre tablas y la estructura de la base de datos
