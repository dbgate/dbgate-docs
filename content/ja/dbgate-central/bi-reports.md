DbGate Central は API のレスポンスを独自の組み込みデータエンジンに読み込むため、それらを組み合わせ、集計し、可視化できます。生の API レスポンスを読みやすい BI レポートに変換します。

## 生のレスポンスからインサイトへ

* データを**集計してピボット**し、サマリーテーブルにまとめます。任意のディメンションによる件数、合計、内訳を表示できます。
* **複数のソースを関連付ける**ことで、異なるエンドポイントの背後にあるデータを 1 つのレポートで結合できます。
* 階層を**ドリルダウン**して、全体像から個々の行へと掘り下げられます。

oData および Shopify のエンドポイント（さらに CSV/JSON/Excel ファイル）を BI ソースとして使用できます。GraphQL API はクエリには最適ですが、現在のところレポートのソースとしては利用できません。代わりに直接参照してクエリを実行してください（[GraphQL API のクエリ](../querying-graphql-apis)を参照）。

## レポートの共有

レポートはスタンドアロンの読み取り専用ビューとして**公開**できます。リンクを知っている人は誰でも、アカウントなしで、また接続にアクセスすることなく、ライブデータを閲覧してドリルダウンできます。
