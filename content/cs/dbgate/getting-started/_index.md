Zprovozněte DbGate a připojte se ke své první databázi. DbGate běží jako desktopová aplikace na Windows, macOS a Linuxu, nebo jako webová aplikace v Dockeru, NPM, AWS a Azure - takže si jej můžete nainstalovat způsobem, který vyhovuje vašemu prostředí. Po instalaci vytvoříte připojení zadáním údajů o serveru (volitelně s SSH tunelem a SSL) a DbGate otevře databázi pro procházení a dotazování.

* [Instalace](installation) - nainstalujte desktopovou aplikaci nebo nasaďte webovou verzi (Docker, NPM, AWS, Azure)
* [Připojení](connection) - přidejte připojení, zvolte režim hesla a nakonfigurujte SSH tunel a SSL
