O DbGate está disponível em vários produtos, criados para diferentes formas de trabalhar com dados. Use esta página para encontrar o produto certo.

| Produto | Hospedagem | Login | Ideal para |
|---|---|---|---|
| [DbGate](/pt/dbgate/) (Community / Premium / Team Premium) | Aplicativo desktop ou web auto-hospedado (Docker, NPM, AWS, Azure) | Opcional (Team Premium) | Cliente completo para servidores de banco de dados SQL e NoSQL, com armazenamento online do [DbGate Cloud](/pt/dbgate/dbgate-cloud/) para conexões e scripts |
| [DbGate Central](/pt/dbgate-central/) | Hospedado, pago, no navegador | Obrigatório | Navegar, consultar e editar APIs GraphQL, oData e Shopify como um banco de dados, com relatórios de BI e um servidor MCP para agentes de IA |
| [DbGate Shopify App](/pt/dbgate-shopify-app/) | Aplicativo Shopify nativo, incorporado ao admin da sua loja | Sessão do Shopify | Visualização/edição em massa dos dados da loja Shopify e geração de feeds de produtos agendados |
| [DbGate Lite](/pt/dbgate-lite/) | Hospedado, gratuito, no navegador | Nenhum | Aprender SQL e realizar trabalhos rápidos e pontuais com arquivos de dados |

O DbGate Lite e o DbGate Central são construídos sobre a mesma grade e o mesmo mecanismo de consultas subjacentes - portanto, filtrar, editar e navegar funcionam da mesma forma em ambos, mas o Lite é gratuito e funciona apenas com bancos de dados e arquivos locais SQLite/DuckDB, enquanto o Central adiciona conexões de API hospedadas, workspaces armazenados na nuvem e recursos para equipes.
