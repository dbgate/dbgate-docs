DbGate は柔軟なテーマ機能をサポートしています。独自のテーマを作成して、さまざまな UI 要素の色を変更できます。

テーマは JSON ファイルとして作成されます。カスタムテーマを作成する最も簡単な方法は、テーマ AI アシスタントを使用することです。

## テーマ AI アシスタント
テーマ AI アシスタントを呼び出すには、設定/テーマを開き、「Customize with AI assistant」ボタンをクリックします。

![Theme settings](https://media.dbgate.io/img/app-settings-themes-light.png)

テーマ AI アシスタントは、指示に従ってテーマをカスタマイズします。どの色をどのように変更したいかを指定できます。たとえば、「プライマリカラーを緑に、背景色をダークグレーにして」のように指示できます。

![screenshot](/screenshots/dbgate-green.png)

AI アシスタントによるテーマの生成には数分かかります。生成される変数は約 280 個あります。テーマが生成されたら、「Apply Theme」ボタンをクリックして新しいテーマを使用できます。また、「Save theme」ボタンを使ってテーマを JSON ファイルとして保存することもできます。保存されたすべてのテーマは、テーマ選択画面で利用できるようになります。テーマの管理（名前の変更、編集、削除）は、ファイルウィジェット {{< mdi "file" >}} でも行えます。

## DbGate Cloud でのテーマの共有
DbGate Cloud を使って、他の DbGate ユーザーとテーマを共有できます。テーマを共有するには、[DbGate ナレッジベースリポジトリ](https://github.com/dbgate/dbgate-knowledge-base)でプルリクエストを作成してください。テーマは folder-Themes ディレクトリに保存されています。例については既存のテーマを参照してください。テーマの JSON ファイルをそのディレクトリにコピーして、プルリクエストを作成するだけです。プルリクエストがマージされると、あなたのテーマがテーマ選択画面ですべての DbGate ユーザーに利用可能になります。
