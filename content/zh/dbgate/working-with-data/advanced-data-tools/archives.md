归档是包含 JSONL (NDJSON) 格式数据的文件夹。DbGate 可以非常高效地处理它们，你可以将它们导入数据库、导出为其他格式，或者直接编辑归档中的数据。归档就像一个存储在本地文件中的非常快速且轻量的数据库。

## JSONL 格式
DbGate 在内部各处都使用 JSONL 格式。JSONL 是文本文件，其中每一行包含一个 JSON 字符串化的数据行。DbGate 假定第一行可以包含表头（同样是 JSON 格式），其中带有表结构。当你使用动态结构的 JSONL（不带固定的第一行）时，该格式是标准化的，可以被载入到许多其他工具中。

## 归档文件夹
归档以文件夹的形式组织，其中包含 JSONL 文件。它的结构与数据库类似。你可以将整个数据库导出为新的归档 - 每个表导出为一个 JSON 文件，得益于表头行，表结构也会被保留。

## 查看和编辑归档文件
你可以用不同的模式打开 JSONL 文件：
- 右键菜单 "Open" - 打开数据网格，可以对 JSONL 数据进行排序、筛选和编辑
- 右键菜单 "Open in text editor" - 可以手动编辑 JSONL 文件

## 归档与数据库模型
归档文件夹也用作数据库模型的存储。你可以在数据库右键菜单中选择 "Export DB model" 导出数据库模型。然后你可以编辑该模型（表结构使用 YAML 文件，视图和存储过程使用 SQL 文件），将其与真实数据库比较，并部署到数据库中
