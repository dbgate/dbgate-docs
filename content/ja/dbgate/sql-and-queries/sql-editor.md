SQL エディターは、接続に対して SQL スクリプトを記述して実行する場所です。ツールバーの {{< mdi "flash" >}} 「New query」ボタン、または接続やデータベースのコンテキストメニューから開けます。

![SQL editor](https://media.dbgate.io/img/common-data-browser-light.png)

## SQL の実行

* **スクリプトの実行** - {{< mdi "play" >}} 実行ボタン (または F5) でスクリプト全体を実行します。
* **現在のステートメントの実行** - カーソル位置のステートメントのみを実行します。
* **選択範囲の実行** - スクリプトの一部を選択すると、選択したテキストのみが実行されます。
* 結果はエディターの下の結果グリッドに表示されます。複数の結果セットは別々のタブに表示されます。
* メッセージ、行数、エラーは **Messages** タブに表示されます。

## 編集支援機能

* **SQL コードフォーマッター** - 現在のスクリプトを再フォーマットし、インデントと大文字・小文字を統一します。
* **コード補完** - 接続先データベースのスキーマに基づいて、テーブル、列、キーワードの候補を提示します。
* **JOIN ヘルパー** - 「Add SQL join」ユーティリティは外部キーから `LEFT`/`INNER`/`RIGHT JOIN` 句を生成するため、結合条件を手入力する必要がありません。

## 結果の操作

結果グリッドは [データブラウザー](/ja/dbgate/working-with-data/data-browser/) と同じエンジンを使用しているため、[フィルタリングと並べ替え](/ja/dbgate/working-with-data/data-filtering/)、さまざまな形式でのセルのコピー、結果の [エクスポート](/ja/dbgate/working-with-data/export-import/) が可能です。

### クエリ結果とビューの編集 *(Premium)*

DbGate が結果を単一のテーブルまたは更新可能なビューにマッピングできる場合、クエリ結果は編集可能です。結果グリッドで直接セルを編集し、生成された変更スクリプトを確認してからデータベースに保存できます。これは [データブラウザー](/ja/dbgate/working-with-data/data-browser/) と同じステージング型の変更ワークフローです。ビューの編集にも対応しています。

> 編集可能なクエリ結果と編集可能なビューは DbGate 7.2 で導入されました。

## トランザクション制御

エディターからトランザクションを制御できます。明示的なトランザクション内で実行し、変更をコミットまたはロールバックできるため、データを変更するスクリプトをテストする際に便利です。

## その他のエディター

* **Mongo JavaScript エディター** - MongoDB 接続向けに、NodeJS 構文で Mongo スクリプトを記述して実行します。
* **Redis** - Redis のキーツリーを参照し、選択したキーからスクリプトを生成して、Redis スクリプトを実行します。
