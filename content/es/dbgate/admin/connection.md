## Pestaña Conexiones
Configure las conexiones disponibles en DbGate. Las conexiones deben estar asignadas a usuarios o roles para estar disponibles.

![Administración de conexiones - DbGate](https://media.dbgate.io/img/connection-administration-light.png)

## Acceso directo a la base de datos de almacenamiento
El usuario administrador también tiene acceso a la base de datos de almacenamiento interna, por lo que puede realizar operaciones directamente sobre la base de datos (por ejemplo, exportaciones/importaciones de usuarios, etc.). Este permiso también se puede conceder a cualquier otro usuario, permiso "Almacenamiento interno"
