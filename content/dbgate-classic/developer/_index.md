Go beyond the GUI and put DbGate to work in your own tools and pipelines. Automate exports, imports and deployments with JavaScript that runs in the app or from the command line, query GraphQL/OData/OpenAPI endpoints as if they were databases, and extend DbGate with your own plugins for database drivers or file formats. This section also documents the scripting API and the SQL front matter used by the knowledge base.

* [API Connections](api-connections) - browse and query GraphQL, OData and OpenAPI REST endpoints
* [API documentation](apidoc) - reference for the DbGate scripting API
* [Plugin development](plugin-development) - build plugins for database engines and file formats
* [Scripting](scripting) - automate tasks with JavaScript, in the app or from the command line
* [SQL Front Matter](sql-front-matter) - annotate SQL scripts for the knowledge base and charts
