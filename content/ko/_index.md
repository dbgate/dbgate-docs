DbGate는 데이터를 다루는 다양한 방식에 맞춰 만들어진 여러 제품으로 제공됩니다. 이 페이지에서 자신에게 맞는 제품을 찾아보세요.

| 제품 | 호스팅 | 로그인 | 적합한 용도 |
|---|---|---|---|
| [DbGate](/ko/dbgate/) (Community / Premium / Team Premium) | 데스크톱 앱 또는 자체 호스팅 웹(Docker, NPM, AWS, Azure) | 선택 사항 (Team Premium) | SQL 및 NoSQL 데이터베이스 서버를 위한 모든 기능을 갖춘 클라이언트로, 연결과 스크립트를 위한 [DbGate Cloud](/ko/dbgate/dbgate-cloud/) 온라인 저장소 제공 |
| [DbGate Central](/ko/dbgate-central/) | 호스팅형, 유료, 브라우저 기반 | 필수 | GraphQL, oData, Shopify API를 데이터베이스처럼 탐색, 조회, 편집하며 BI 리포트와 AI 에이전트용 MCP 서버 제공 |
| [DbGate Shopify App](/ko/dbgate-shopify-app/) | 네이티브 Shopify 앱, 스토어 관리자 화면에 내장 | Shopify 세션 | Shopify 스토어 데이터의 대량 조회/편집 및 예약된 상품 피드 생성 |
| [DbGate Lite](/ko/dbgate-lite/) | 호스팅형, 무료, 브라우저 기반 | 없음 | SQL 학습 및 데이터 파일을 이용한 빠른 임시 작업 |

DbGate Lite와 DbGate Central은 동일한 기반 그리드 및 쿼리 엔진 위에 구축되어 있습니다. 따라서 필터링, 편집, 탐색은 두 제품에서 동일하게 느껴지지만, Lite는 무료이며 로컬 SQLite/DuckDB 데이터베이스와 파일에서만 동작하는 반면, Central은 호스팅형 API 연결, 클라우드에 저장되는 워크스페이스, 팀 기능을 추가로 제공합니다.
