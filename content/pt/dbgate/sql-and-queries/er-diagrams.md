Diagramas ER (entidade-relacionamento) visualizam suas tabelas e as relações entre elas. Gere um diagrama para todo o banco de dados ou para um conjunto selecionado de tabelas.

![Diagrama ER](https://media.dbgate.io/img/database-diagram-light.png)

## Criando um diagrama

* Exiba as relações de uma única tabela ou a estrutura completa do banco de dados.
* Adicione tabelas a um diagrama existente a partir da árvore de objetos do banco de dados.

## Personalizando o diagrama *(configurações avançadas são Premium)*

* **Cores e grupos** - altere a cor de uma tabela e defina grupos lógicos de tabelas.
* **Escolher colunas** - exiba todas as colunas, apenas as colunas not-null ou apenas as colunas de chave primária.
* **Atributos** - configure se os tipos de dados e os indicadores NULL/NOT NULL são exibidos.

## Exportação

Exporte o diagrama para uma página HTML simples e autocontida para compartilhá-lo ou incluí-lo na documentação.

Os diagramas são armazenados como outros objetos do DbGate e podem ser compartilhados por meio de pastas do [DbGate Cloud](/pt/dbgate/dbgate-cloud/).
