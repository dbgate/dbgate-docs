DbGate propose plusieurs outils de données avancés adaptés à des scénarios spécifiques :

- [Archives de données](archives) - données de tables stockées dans des dossiers (au format NDJSON) sur votre ordinateur local. Vous pouvez parcourir et modifier ces données de la même manière que vous parcourez les tables d'une base de données
- [Déployeur de données](data-deployer) - comparez et synchronisez visuellement les données entre une archive de données et une base de données réelle
- [Réplicateur de données](data-replicator) - répliquez vos données d'une archive de données vers une base de données, adapté à une exécution depuis l'application DbGate ou depuis la ligne de commande
