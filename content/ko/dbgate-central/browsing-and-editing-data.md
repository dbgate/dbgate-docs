oData 서비스를 비롯한 여러 엔드포인트를 일반 데이터베이스 테이블처럼 다룰 수 있습니다. 코드를 작성할 필요 없이 스프레드시트와 유사한 빠른 그리드에서 결과를 탐색하고, 편집하고, 필터링하고, 정렬할 수 있습니다.

## 강력한 데이터 그리드

* 모든 열에서 **필터링 및 정렬**하여 대용량 결과 집합을 단 몇 초 만에 좁힐 수 있습니다.
* **인라인으로 편집**하고 변경 사항을 엔드포인트에 적용하며, 작업 중에는 실행 취소/다시 실행을 사용할 수 있습니다.
* 기본 제공되는 **열 값 히스토그램**으로 데이터의 형태를 한눈에 파악할 수 있습니다.
* 데이터를 다른 곳에서 사용해야 할 때 언제든지 결과를 CSV, JSON 및 Excel로 **내보낼** 수 있습니다.

이 그리드는 DbGate 전반에서 사용되는 동일한 엔진이므로, 여기서 익힌 모든 내용은 SQLite, DuckDB 및 BI 리포트에도 그대로 적용됩니다.

## JSON 검사 및 편집

API 응답은 평면적인 경우가 거의 없습니다. 중첩된 JSON 값에서 셀 드롭다운을 열면 구조화된 응답을 검사하고, 객체와 배열을 펼치고, 변경 사항을 엔드포인트에 다시 기록하는 양방향 편집으로 값을 편집할 수 있습니다.
