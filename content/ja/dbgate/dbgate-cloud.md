DbGate Cloud は、接続、SQL スクリプト、その他のオブジェクトのためのオンラインストレージです。また、便利な SQL スクリプトの公開ナレッジベースも提供しています。

> DbGate Cloud は、**デスクトップ**版 DbGate アプリのためのストレージコンパニオンです（接続、SQL スクリプト、共有フォルダ）。ブラウザだけで使えるホスト型アプリをお探しですか？ [DbGate Central](/ja/dbgate-central/) をご覧ください。

## サインイン
DbGate Cloud を使用するには、サインインが必要です。左パネルの {{< mdi "account-remove-outline" >}} アイコンを使用してください。

クラウドストレージは常にお使いのメールアドレスに関連付けられます。  
次の認証プロバイダーのいずれかを選択できます:
* GMail
* GitHub
* メール - ワンタイムのサインイン用マジックリンクがメールで送信されます

DbGate のサーバーはパスワードを保存しません。

## クラウドに保存された接続を使う
サインイン後、クラウドの内容は {{< mdi "cloud-key" >}} ウィジェットの下に表示されます。デフォルトでは、Private フォルダ（書き込みアクセス権付き）が表示されます。

接続をクラウドに保存する:
* 接続のコンテキストメニューで「Copy to cloud folder」を選択します
* {{<mdi "plus-thick" >}} をクリックし、「Add connection on cloud」を選択します

## どの接続がクラウドに保存されているか？
* クラウドの接続は常に {{< mdi "cloud-key" >}} ウィジェットの下にあります
* ローカルに保存された接続は {{< mdi "database" >}} ウィジェットの下にあります

## フォルダの操作
Private フォルダ以外にも、さらにフォルダを作成できます（Premium エディションが必要です）。

{{<mdi "plus-thick" >}} ボタンの下には、次のコマンドがあります:
* New shared folder - 新しい共有フォルダを作成します。デフォルトでは自分だけがアクセスでき、他のユーザーを招待できます
* Add existing shared folder - 共有フォルダ（他のユーザーが作成したもの）への招待リンクをお持ちの場合は、ここで使用します

フォルダを他の人と共有したい場合は、フォルダを右クリックして「Copy invite link」を選択してください

## 共有フォルダの権限
* Admin - フォルダへのフルアクセス権を持ち、他の人を招待したり内容を書き込んだりできます
* Write - 内容の書き込み/削除はできますが、他の人を招待することはできません
* Read - フォルダの内容の読み取りのみ可能です。この権限は、サーバー定義の接続内で利用可能なデータベースには適用されないことにご注意ください

## Community エディションでの共有フォルダ
Community エディションでは、Premium ユーザーが作成した共有フォルダを使用できますが、自分で共有フォルダを作成することはできません。これは、Premium エディションを使用しているチームが、Community エディションを使用している他のチームメンバーと接続、SQL ファイル、ER ダイアグラムを共有できるようにすることを目的としています。

## 公開ナレッジベース
公開ナレッジベースは、SQL パフォーマンスチューニング、デッドロック分析、インデックス使用状況などのタスクに役立つ SQL スクリプトとチャートのコレクションです。ナレッジベースはすべてのエディションで利用できますが、チャートは Premium エディションでのみ利用できます。

左のウィジェットパネルにある {{< mdi "cloud-search" >}} アイコンの下で、すべての項目を確認できます。  
グレー表示されたスクリプトは、現在選択されているデータベースと互換性のないスクリプトを示します。

ご自身の SQL スクリプトでナレッジベースを充実させたい場合は、[dbgate-knowledge-base](https://github.com/dbgate/dbgate-knowledge-base) の GIT リポジトリにプルリクエストを作成してください。

ナレッジベース内のスクリプトには [SQL front matter](/ja/dbgate/developer/sql-front-matter) 構文で注釈が付けられています
