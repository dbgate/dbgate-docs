データデプロイヤーを使用すると、**アーカイブフォルダー**内のデータと**実際のデータベース**を視覚的に比較して同期できます
![DbGate data duplicator screenshot](https://media.dbgate.io/img/data-deployer-light.png)

## データデプロイヤーの実行
データデプロイヤーは、データベースのコンテキストメニューまたはアーカイブフォルダーのコンテキストメニューから実行できます。データベースから実行する場合は、アーカイブを選択するよう求められます。アーカイブから実行する場合は、データデプロイヤーは現在のデータベースで開始されます。

## 設定
- データベースサーバー、データベース - 操作対象のデータベースを選択します
- データアーカイブ - 比較および同期に使用するデータの入ったフォルダーを選択します
### テーブル関連
- キー（照合列） - データベースとアーカイブの間で行を照合するために使用する列を選択します
### レプリケーター設定
以下の設定（「テーブル」 - デプロイおよびグローバルデータデプロイ設定）はレプリケーター固有のもので、[データレプリケーター](data-replicator)のトピックで説明しています

## データの差分のコピー
データデプロイヤーは、アーカイブ内のデータとデータベース内のデータの差分を表示します。差分のあるセルをいくつか選択すると、その差分をアーカイブまたはデータベースに書き込むことができます。これらのセルが選択されると、右下隅に同期を行うためのボタンが表示されます:
- Write x rows, y columns to archive - 選択したセルをデータベースからアーカイブにコピーします。
- Write x rows, y columns to database - 選択したセルをアーカイブからデータベースにコピーします。最初に変更 SQL を含む確認ダイアログが表示されます。

## データレプリケーターのアクション
- Deploy into DB - このアクションは、設定された内容で変更をデータベースにデプロイします
- Generate shell - このアクションは、デプロイを実行する JavaScript ファイルを作成します。このファイルはコマンドラインから実行できます
- Generate SQL - アーカイブからデータベースへ変更をデプロイする SQL を作成します

これらのアクションの詳細は[データレプリケーター](data-replicator)のトピックを参照してください
