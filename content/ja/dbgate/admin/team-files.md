チームファイルとは、DbGate の内部ストレージに保存される SQL、ダイアグラム、その他のファイルです。デスクトップ版 DbGate はユーザーフォルダーにファイルを保存し、Team エディションでも同様の方法（docker ボリューム内）でファイルを保存できますが、より適切なのはストレージデータベースにファイルを保存する方法です。ストレージデータベースは、DbGate コンテナーが再作成されても再作成されません。

- ディスクファイル
    - ディスクまたは docker ボリュームに保存されるファイル
    - docker ボリュームを明示的に定義していない場合（例: docker-compose.yaml で）、コンテナーが再作成されるとファイルも再作成されます。
- チームファイル
    - ストレージデータベースに保存されるファイル
    - docker ボリュームを定義しなくても、コンテナーが再作成されたときに失われません
    - ユーザーやロールに対して、きめ細かなアクセス権限を定義できます

## SQL ファイルをチームファイルとして保存する
SQL ファイルを保存するときに、「Save to team folder」チェックボックスをオンにするだけです。ファイルはチームファイルとして保存されます。
