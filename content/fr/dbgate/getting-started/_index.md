Installez DbGate, lancez-le et connectez-vous à votre première base de données. DbGate fonctionne comme une application de bureau sous Windows, macOS et Linux, ou comme une application web dans Docker, NPM, AWS et Azure - vous pouvez donc l'installer de la manière qui convient le mieux à votre environnement. Une fois l'installation terminée, vous créez une connexion en saisissant les informations de votre serveur (avec, en option, un tunnel SSH et SSL), et DbGate ouvre la base de données pour l'explorer et l'interroger.

* [Installation](installation) - installez l'application de bureau ou déployez la version web (Docker, NPM, AWS, Azure)
* [Connexion](connection) - ajoutez une connexion, choisissez un mode de mot de passe et configurez le tunnel SSH et SSL
