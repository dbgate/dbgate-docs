Tudo o que você faz com as linhas reais do seu banco de dados está aqui. Navegue e edite dados de tabelas em uma grade rápida e semelhante ao Excel, refine-os com filtros poderosos e navegue entre tabelas relacionadas por meio de chaves estrangeiras e visualizações mestre/detalhe. Quando precisar de mais do que uma grade, transforme os resultados em gráficos ou mapas, use o chat de banco de dados com IA, mova dados com exportação/importação ou mantenha arquivos NDJSON locais deles.

* [Navegador e editor de dados](data-browser) - a visualização em grade, edição inline e navegação por dados relacionados
* [Filtragem de dados](data-filtering) - sintaxe das expressões de filtro
* [Exportação e importação](export-import) - mova dados para dentro e para fora das tabelas
* [Gráficos](charts) - visualize os resultados das consultas
* [Mapas](maps) - exiba dados GEO em um mapa
* [Perspectivas](perspectives) - visualizações aninhadas e somente leitura sobre dados relacionados complexos
* [Recursos de IA](ai-features) - chat de banco de dados, assistente de SQL e explicação de erros *(Premium)*
* [Ferramentas avançadas de dados](advanced-data-tools) - arquivos, implantador de dados e replicador de dados
