アーカイブは、JSONL (NDJSON) 形式のデータを格納したフォルダーです。DbGate では、アーカイブを非常に効率的に扱うことができます。データベースへインポートしたり、他の形式へエクスポートしたり、アーカイブ内のデータを直接編集したりできます。アーカイブは、ローカルファイルに保存された非常に高速で軽量なデータベースのように動作します。

## JSONL 形式
DbGate は内部のあらゆる場所で JSONL 形式を使用しています。JSONL はテキストファイルで、各行に JSON 文字列化された行データが含まれます。DbGate は、最初の行にテーブル構造を持つヘッダー (これも JSON 形式) が含まれる場合があることを前提としています。動的な構造の JSONL (先頭の固定行なし) を使用する場合、この形式は標準化されており、他の多くのツールに読み込むことができます。

## アーカイブフォルダー
アーカイブは、JSONL ファイルを含むフォルダーとして構成されます。データベースと似た構造を持っています。そのため、データベース全体を新しいアーカイブにエクスポートできます。各テーブルは 1 つの JSON ファイルにエクスポートされ、ヘッダー行のおかげでテーブル構造も保持されます。

## アーカイブファイルの表示と編集
JSONL ファイルはさまざまなモードで開くことができます。
- コンテキストメニューの「Open」 - データグリッドを開き、JSONL データの並べ替え、フィルタリング、編集ができます
- コンテキストメニューの「Open in text editor」 - JSONL ファイルを手動で編集できます

## アーカイブと DB モデル
アーカイブフォルダーは、DB モデルの保存先としても使用されます。データベースのコンテキストメニューの「Export DB model」から DB モデルをエクスポートできます。エクスポートしたモデル (テーブル構造は YAML ファイル、ビューやストアドプロシージャは SQL ファイル) を編集し、実際のデータベースと比較して、データベースへデプロイすることができます。
