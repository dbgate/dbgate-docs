DbGate Central carica le risposte delle tue API nel proprio motore dati integrato, così puoi combinarle, aggregarle e visualizzarle - trasformando le risposte grezze delle API in report BI leggibili.

## Dalle risposte grezze all'analisi

* **Aggrega e crea tabelle pivot** con i tuoi dati per ottenere tabelle riepilogative - conteggi, somme e suddivisioni per qualsiasi dimensione.
* **Metti in relazione più origini** in modo che un report possa unire dati che si trovano dietro endpoint diversi.
* **Esplora in dettaglio** le gerarchie per passare dalla visione d'insieme alle singole righe.

Gli endpoint oData e Shopify (e i file CSV/JSON/Excel) possono essere usati come origini BI. Le API GraphQL sono ottime per le query, ma al momento non sono disponibili come origine per i report - esplorale e interrogale direttamente (vedi [Interrogare le API GraphQL](../querying-graphql-apis)).

## Condividere un report

I report possono essere **pubblicati** come vista autonoma e di sola lettura. Chiunque abbia il link vede i dati in tempo reale e può esplorarli in dettaglio, senza un account e senza accesso alla tua connessione.
