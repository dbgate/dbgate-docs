title: Documentación de DbGate

DbGate está disponible en varios productos, creados para diferentes formas de trabajar con datos. Utilice esta página para encontrar el más adecuado.

| Producto | Alojamiento | Inicio de sesión | Ideal para |
|---|---|---|---|
| [DbGate](/es/dbgate/) (Community / Premium / Team Premium) | Aplicación de escritorio o web autoalojada (Docker, NPM, AWS, Azure) | Opcional (Team Premium) | Cliente con todas las funciones para servidores de bases de datos SQL y NoSQL, con almacenamiento en línea [DbGate Cloud](/es/dbgate/dbgate-cloud/) para conexiones y scripts |
| [DbGate Central](/es/dbgate-central/) | Alojado, de pago, en el navegador | Obligatorio | Explorar, consultar y editar APIs de GraphQL, oData y Shopify como si fueran una base de datos, con informes de BI y un servidor MCP para agentes de IA |
| [DbGate Shopify App](/es/dbgate-shopify-app/) | Aplicación nativa de Shopify, integrada en el panel de administración de su tienda | Sesión de Shopify | Visualización y edición masiva de datos de tiendas Shopify y generación de feeds de productos programados |
| [DbGate Lite](/es/dbgate-lite/) | Alojado, gratuito, en el navegador | Ninguno | Aprender SQL y trabajar de forma rápida y puntual con archivos de datos |

DbGate Lite y DbGate Central están construidos sobre el mismo motor de cuadrícula y de consultas subyacente, por lo que el filtrado, la edición y la exploración se sienten igual en ambos, pero Lite es gratuito y funciona solo con bases de datos y archivos locales de SQLite/DuckDB, mientras que Central añade conexiones a APIs alojadas, espacios de trabajo almacenados en la nube y funciones para equipos.
