DbGate는 데이터베이스 구조를 비교하고 변경 사항을 배포할 수 있습니다 *(Premium)*. 이는 여러 환경을 동기화된 상태로 유지하고 스키마를 버전 관리하는 데 유용합니다.

![Compare database](https://media.dbgate.io/img/compare-database-settings-light.png)

## 데이터베이스 비교

* **두 데이터베이스 비교** - 컬럼, 뷰 정의 및 기타 SQL 객체의 차이점을 찾습니다.
* **구조 동기화** - 한 데이터베이스를 다른 데이터베이스와 일치시키는 데 필요한 작업을 생성하고 실행합니다.
* **YAML 모델과 비교** - 실제 데이터베이스를 YAML로 저장된 모델과 비교하고 차이점을 배포합니다.
* **설정** - 비교를 제어합니다. 예를 들어 외래 키를 무시하거나, 특정 객체를 제외하거나, 수행할 동기화 작업을 선택할 수 있습니다.

## 데이터베이스 모델 내보내기

* **폴더로 스캐폴딩** - 기존 데이터베이스의 모델을 폴더 또는 단일 JSON 파일로 저장합니다.
* **YAML 테이블 파일** - 테이블은 Git 저장소에 보관할 수 있는 간단한 YAML 파일로 저장됩니다.
* **SQL 정의 파일** - 뷰, 저장 프로시저 및 함수는 SQL 파일로 저장됩니다.

## 배포

Compare 도구를 사용하여 시각적으로 모델을 배포하거나, CI/CD 파이프라인의 일부로 명령줄에서 배포할 수 있습니다. 모델 파일 형식과 CLI 워크플로에 대해서는 [데이터베이스 배포](dbdeploy)를 참조하세요.
