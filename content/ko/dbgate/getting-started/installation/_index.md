DbGate는 다양한 플랫폼에서 사용할 수 있으며, 설치 과정은 플랫폼에 따라 다릅니다.

## Windows
Windows는 msi 설치 프로그램과 포터블 ZIP 설치를 지원합니다. 자동 업데이트는 MSI 설치 프로그램에서 지원됩니다.

## Linux
Linux는 snap 패키지와 AppImage 배포를 지원합니다. 두 가지 모두 자동 업데이트를 지원합니다(SNAP은 자체적으로 지원합니다).

## Mac
Mac에서는 DMG 설치 프로그램을 사용할 수 있습니다. 3가지 패키지가 제공됩니다:
  - Apple (arm64) - 새로운 Apple M1, M2, M3, M4 프로세서용
  - Intel (x86) - 구형 x86 프로세서용
  - Apple+Intel - 두 패키지를 하나의 설치 프로그램으로 제공

## Docker 
Team Premium 에디션의 경우 [Team Premium on Docker ](docker-tp)의 안내를 따라 주세요.

무료 Community 에디션의 경우 [docker hub](https://hub.docker.com/r/dbgate/dbgate)의 안내를 따라 주세요.


## NPM
NPM에서 DbGate의 웹 버전을 설치할 수도 있습니다. [npmjs](https://www.npmjs.com/package/dbgate-serve)의 안내를 따라 주세요.

## Amazon (AWS)
[Amazon 마켓플레이스의 DbGate](https://aws.amazon.com/marketplace/pp/prodview-glw7okfnhf4cy)를 열어 보세요. 최상의 사용자 경험을 위해서는 t2.medium 인스턴스 유형을 권장하지만, 프리 티어에서 사용할 수 있는 t2.micro도 소수의 사용자에게는 충분합니다.

[AWS에 대해 자세히 보기](aws)

## Azure
[Azure 마켓플레이스의 DbGate](https://azuremarketplace.microsoft.com/en-us/marketplace/apps/sprinxsystemsas1582034211947.dbgate_azure_vm?tab=Overview)를 열어 보세요. RAM 2GB의 가상 머신을 권장합니다.

[Azure에 대해 자세히 보기](azure)
