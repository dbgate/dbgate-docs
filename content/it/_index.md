DbGate è disponibile in diversi prodotti, pensati per modi differenti di lavorare con i dati. Usa questa pagina per trovare quello giusto.

| Prodotto | Hosting | Accesso | Ideale per |
|---|---|---|---|
| [DbGate](/it/dbgate/) (Community / Premium / Team Premium) | App desktop, oppure web self-hosted (Docker, NPM, AWS, Azure) | Facoltativo (Team Premium) | Client completo per server di database SQL e NoSQL, con l'archiviazione online [DbGate Cloud](/it/dbgate/dbgate-cloud/) per connessioni e script |
| [DbGate Central](/it/dbgate-central/) | Hosted, a pagamento, nel browser | Obbligatorio | Esplorare, interrogare e modificare API GraphQL, oData e Shopify come un database, con report BI e un server MCP per agenti AI |
| [DbGate Shopify App](/it/dbgate-shopify-app/) | App Shopify nativa, integrata nell'amministrazione del tuo store | Sessione Shopify | Visualizzare/modificare in blocco i dati dello store Shopify e generare feed di prodotti pianificati |
| [DbGate Lite](/it/dbgate-lite/) | Hosted, gratuito, nel browser | Nessuno | Imparare SQL e lavorare in modo rapido e ad hoc con i file di dati |

DbGate Lite e DbGate Central sono costruiti sullo stesso motore di griglia e di query sottostante - quindi il filtraggio, la modifica e l'esplorazione risultano identici in entrambi, ma Lite è gratuito e funziona solo con database e file SQLite/DuckDB locali, mentre Central aggiunge connessioni ad API hosted, workspace archiviati nel cloud e funzionalità per i team.
