SQL 편집기는 연결에 대해 SQL 스크립트를 작성하고 실행하는 곳입니다. 도구 모음의 {{< mdi "flash" >}} "새 쿼리" 버튼이나 연결 또는 데이터베이스의 컨텍스트 메뉴에서 열 수 있습니다.

![SQL editor](https://media.dbgate.io/img/common-data-browser-light.png)

## SQL 실행

* **스크립트 실행** - {{< mdi "play" >}} 실행 버튼(또는 F5)으로 전체 스크립트를 실행합니다.
* **현재 문 실행** - 커서 아래에 있는 문만 실행합니다.
* **선택 영역 실행** - 스크립트의 일부를 선택하면 선택한 텍스트만 실행됩니다.
* 결과는 편집기 아래의 결과 그리드에 표시됩니다. 여러 결과 집합은 별도의 탭에 표시됩니다.
* 메시지, 행 수 및 오류는 **Messages** 탭에 표시됩니다.

## 편집 도우미

* **SQL 코드 포매터** - 일관된 들여쓰기와 대소문자를 위해 현재 스크립트의 서식을 다시 지정합니다.
* **코드 자동 완성** - 연결된 데이터베이스 스키마를 기반으로 한 테이블, 열 및 키워드 제안입니다.
* **조인 도우미** - "Add SQL join" 유틸리티는 외래 키에서 `LEFT`/`INNER`/`RIGHT JOIN` 절을 생성하므로 조인 조건을 직접 입력할 필요가 없습니다.

## 결과 다루기

결과 그리드는 [데이터 브라우저](/ko/dbgate/working-with-data/data-browser/)와 동일한 엔진을 사용하므로 [필터링 및 정렬](/ko/dbgate/working-with-data/data-filtering/)하고, 다양한 형식으로 셀을 복사하며, 결과를 [내보낼](/ko/dbgate/working-with-data/export-import/) 수 있습니다.

### 쿼리 결과 및 뷰 편집 *(Premium)*

DbGate가 결과를 단일 테이블 또는 업데이트 가능한 뷰로 매핑할 수 있는 경우 쿼리 결과를 편집할 수 있습니다. 결과 그리드에서 셀을 직접 편집하고, 생성된 변경 스크립트를 검토한 다음 데이터베이스에 저장하십시오 - [데이터 브라우저](/ko/dbgate/working-with-data/data-browser/)와 동일한 스테이징된 변경 워크플로입니다. 뷰 편집도 지원됩니다.

> 편집 가능한 쿼리 결과와 편집 가능한 뷰는 DbGate 7.2에서 도입되었습니다.

## 트랜잭션 제어

편집기에서 트랜잭션을 제어할 수 있습니다 - 명시적 트랜잭션 내에서 실행하고 변경 사항을 커밋하거나 롤백할 수 있으며, 이는 데이터를 수정하는 스크립트를 테스트할 때 유용합니다.

## 기타 편집기

* **Mongo JavaScript 편집기** - MongoDB 연결의 경우 NodeJS 구문을 사용하여 Mongo 스크립트를 작성하고 실행합니다.
* **Redis** - Redis 키 트리를 탐색하고, 선택한 키에서 스크립트를 생성하며, Redis 스크립트를 실행합니다.
