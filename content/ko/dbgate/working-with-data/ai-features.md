DbGate에는 여러 AI 기반 기능이 포함되어 있습니다 *(Premium 및 Team Premium)*. 이 기능들은 API 키나 별도의 설정 없이 모든 Premium 사용자가 사용할 수 있습니다. DbGate는 자체 AI 게이트웨이를 사용하여 요청을 LLM 공급자에게 전달합니다.

![Database chat](https://media.dbgate.io/img/database-chat-light.png)

## 데이터베이스 채팅

데이터베이스 채팅은 데이터베이스 스키마와 데이터를 모두 이해하는 AI 챗봇입니다.

* **자연스러운 대화** - 어떤 자연어로든 질문하고 답변이나 바로 실행할 수 있는 SQL을 받아보세요.
* **컨텍스트 인식** - 모델이 스키마와 (권한이 있는 경우) 실제 데이터를 알고 있으므로 올바른 조인, 필터, 집계를 제안합니다.
* **반복적 개선** - "날짜 필터 추가" 또는 "고객별로 그룹화"와 같은 명령으로 다듬으면 쿼리가 즉시 업데이트됩니다.
* **차트** - 결과를 바탕으로 막대, 원형, 선 차트를 요청할 수 있습니다.
* **컨설턴트 모드** - 저장 프로시저와 뷰를 분석할 수 있어 "프로시저 X를 설명해줘" 또는 "프로시저 Y의 영향을 받는 테이블은 무엇인가" 같은 질문을 할 수 있습니다. DbGate는 어떤 객체가 분석되었는지 보여줍니다.

### SQL 실행 - 안전이 우선

데이터베이스 채팅은 질문에 답하기 위해 SQL을 실행할 수 있습니다. 방식은 직접 선택할 수 있습니다.

* **SQL 실행 전 확인 (기본값)** - DbGate가 각 쿼리를 실행하기 전에 확인을 요청합니다.
* **SQL 자동 실행** - `SELECT`가 아닌 쿼리는 여전히 확인이 필요합니다.
* **실행하지 않고 SQL만 제안** - 채팅은 쿼리만 표시하며, 데이터베이스의 데이터가 LLM으로 전송되지 않습니다.

제안된 쿼리가 실패하면 DbGate는 오류를 모델에 다시 보내고, 모델은 대개 쿼리를 자동으로 수정합니다.

## SQL AI 어시스턴트

채팅을 SQL 어시스턴트로 사용하고 - "매출 기준 상위 10명의 고객에 대한 SQL 쿼리를 작성해줘" - 결과를 [SQL 편집기](/ko/dbgate/sql-and-queries/sql-editor/) 탭에서 열어보세요.

## SQL 오류 설명

오류 메시지 옆의 **Explain**을 클릭하면 무엇이 잘못되었고 어떻게 고칠 수 있는지에 대한 AI 설명을 얻을 수 있습니다.
