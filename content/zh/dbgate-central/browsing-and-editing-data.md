像操作普通数据库表一样使用 oData 服务和其他端点 —— 在快速的类电子表格网格中浏览、编辑、筛选和排序结果，无需编写任何代码。

## 强大的数据网格

* **筛选和排序**任意列，在几秒内缩小大型结果集的范围。
* **就地编辑**并将更改应用回端点，工作时支持撤销/重做。
* 通过内置的**列值直方图**一眼了解数据的分布形态。
* 当需要在其他地方使用数据时，可将结果**导出**为 CSV、JSON 和 Excel。

该网格与 DbGate 中各处使用的引擎相同，因此您在这里学到的一切都可以应用到 SQLite、DuckDB 和 BI 报表中。

## 检查和编辑 JSON

API 响应很少是扁平的。在嵌套的 JSON 值上打开单元格下拉菜单，即可检查结构化响应、展开对象和数组，并通过双向编辑修改值，将更改写回端点。
