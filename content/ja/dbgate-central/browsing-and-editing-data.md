oData サービスやその他のエンドポイントを、通常のデータベーステーブルと同じように扱えます。コードを書くことなく、高速でスプレッドシートのようなグリッドで結果を閲覧、編集、フィルタリング、並べ替えできます。

## 強力なデータグリッド

* 任意の列を**フィルタリングして並べ替え**、大きな結果セットを数秒で絞り込めます。
* **インラインで編集**して変更をエンドポイントに適用でき、作業中は元に戻す／やり直しも利用できます。
* 組み込みの**列値ヒストグラム**により、データの傾向をひと目で把握できます。
* データを他の場所で使いたいときは、いつでも結果を CSV、JSON、Excel に**エクスポート**できます。

このグリッドは DbGate 全体で使われているものと同じエンジンなので、ここで学んだことはすべて SQLite、DuckDB、BI レポートでもそのまま活かせます。

## JSON の確認と編集

API のレスポンスがフラットであることはめったにありません。ネストされた JSON 値のセルのドロップダウンを開くと、構造化されたレスポンスを確認し、オブジェクトや配列を展開して、双方向編集で値を編集できます。変更内容はエンドポイントに書き戻されます。
