让 DbGate 运行起来并连接到你的第一个数据库。DbGate 可以作为桌面应用程序在 Windows、macOS 和 Linux 上运行，也可以作为 Web 应用程序在 Docker、NPM、AWS 和 Azure 中运行 - 因此你可以选择最适合自己环境的安装方式。安装完成后，你只需输入服务器详细信息（可选配置 SSH 隧道和 SSL）即可创建连接，DbGate 随即会打开该数据库以供浏览和查询。

* [安装](installation) - 安装桌面应用程序或部署 Web 版本（Docker、NPM、AWS、Azure）
* [连接](connection) - 添加连接、选择密码模式，并配置 SSH 隧道和 SSL
