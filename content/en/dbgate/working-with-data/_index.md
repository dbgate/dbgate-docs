Everything you do with the actual rows in your database lives here. Browse and edit table data in a fast, Excel-like grid, narrow it down with powerful filters, and navigate between related tables through foreign keys and master/detail views. When you need more than a grid, turn results into charts or maps, ask the AI-powered database chat, move data with export/import, or keep local NDJSON archives of it.

* [Data browser & editor](data-browser) - the grid view, inline editing and related-data navigation
* [Data filtering](data-filtering) - filter expression syntax
* [Export & import](export-import) - move data in and out of tables
* [Charts](charts) - visualize query results
* [Maps](maps) - show GEO data on a map
* [Perspectives](perspectives) - nested, read-only views over complex related data
* [AI features](ai-features) - database chat, SQL assistant and explain error *(Premium)*
* [Advanced data tools](advanced-data-tools) - archives, data deployer and data replicator
