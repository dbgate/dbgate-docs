Trabalhe com a estrutura dos seus bancos de dados em vez dos dados contidos neles. Projete tabelas, chaves e índices pela interface gráfica com uma prévia do SQL antes que qualquer coisa seja aplicada, compare dois bancos de dados (ou um banco de dados com um modelo YAML) e sincronize as diferenças, e implante modelos visualmente ou pela linha de comando como parte de um pipeline de CI/CD. Esta seção também aborda backup e restauração nativos.

* [Editor de tabelas e schema](schema-editor) - crie e modifique tabelas, chaves e índices pela interface gráfica
* [Deploy de banco de dados](dbdeploy) - arquivos de modelo YAML/SQL e implantação via CLI
* [Comparar e implantar modelos](model-compare-deploy) - compare a estrutura e sincronize bancos de dados *(Premium)*
* [Backup e restauração](backup-restore) - backup e restauração nativos do banco de dados
