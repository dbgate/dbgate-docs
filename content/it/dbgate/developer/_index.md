Vai oltre la GUI e metti DbGate al lavoro nei tuoi strumenti e nelle tue pipeline. Automatizza esportazioni, importazioni e distribuzioni con JavaScript eseguito nell'applicazione o dalla riga di comando, interroga endpoint GraphQL/OData/OpenAPI come se fossero database ed estendi DbGate con i tuoi plugin per driver di database o formati di file. Questa sezione documenta anche l'API di scripting e il front matter SQL utilizzato dalla knowledge base.

* [Connessioni API](api-connections) - esplora e interroga endpoint REST GraphQL, OData e OpenAPI
* [Documentazione API](apidoc) - riferimento per l'API di scripting di DbGate
* [Sviluppo di plugin](plugin-development) - crea plugin per motori di database e formati di file
* [Scripting](scripting) - automatizza le attività con JavaScript, nell'applicazione o dalla riga di comando
* [SQL Front Matter](sql-front-matter) - annota gli script SQL per la knowledge base e i grafici
