DbGate는 특정 시나리오에 적합한 여러 가지 고급 데이터 도구를 제공합니다:

- [데이터 아카이브](archives) - 로컬 컴퓨터의 폴더에 (NDJSON 형식으로) 저장된 테이블 데이터입니다. 데이터베이스의 테이블을 탐색하는 것과 비슷한 방식으로 이 데이터를 탐색하고 편집할 수 있습니다
- [데이터 배포기](data-deployer) - 데이터 아카이브와 실제 데이터베이스 간의 데이터를 시각적으로 비교하고 동기화합니다
- [데이터 복제기](data-replicator) - 데이터 아카이브에서 데이터베이스로 데이터를 복제합니다. DbGate 앱이나 명령줄에서 실행하기에 적합합니다
