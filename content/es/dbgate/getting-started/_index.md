Pon DbGate en marcha y conéctate a tu primera base de datos. DbGate funciona como una aplicación de escritorio en Windows, macOS y Linux, o como una aplicación web en Docker, NPM, AWS y Azure, de modo que puedes instalarlo de la forma que mejor se adapte a tu configuración. Una vez instalado, creas una conexión introduciendo los datos de tu servidor (con túnel SSH y SSL opcionales), y DbGate abre la base de datos para explorarla y consultarla.

* [Instalación](installation) - instala la aplicación de escritorio o despliega la versión web (Docker, NPM, AWS, Azure)
* [Conexión](connection) - añade una conexión, elige un modo de contraseña y configura el túnel SSH y SSL
