Fragen Sie Ihre Daten so ab, wie es Ihnen am besten passt. Schreiben Sie SQL direkt in einem voll ausgestatteten Editor mit Formatierung, Code-Vervollständigung und bearbeitbaren Ergebnissen, oder erstellen Sie Abfragen visuell mit dem Abfrage-Designer - ganz ohne SQL-Kenntnisse. ER-Diagramme runden das Ganze ab, indem sie zeigen, wie Ihre Tabellen zusammenhängen, sodass Sie die Datenbank verstehen können, bevor Sie sie abfragen.

* [SQL-Editor](sql-editor) - Skripte ausführen, SQL formatieren und vervollständigen, Abfrageergebnisse bearbeiten
* [Abfrage-Designer](query-designer) - SQL visuell erstellen, ohne Code zu schreiben
* [ER-Diagramme](er-diagrams) - Tabellenbeziehungen und Datenbankstruktur visualisieren
