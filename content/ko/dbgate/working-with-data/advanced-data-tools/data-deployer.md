데이터 배포기를 사용하면 **아카이브 폴더**의 데이터와 **실제 데이터베이스**의 데이터를 시각적으로 비교하고 동기화할 수 있습니다.
![DbGate data duplicator screenshot](https://media.dbgate.io/img/data-deployer-light.png)

## 데이터 배포기 실행
데이터 배포기는 데이터베이스 컨텍스트 메뉴 또는 아카이브 폴더 컨텍스트 메뉴에서 실행할 수 있습니다. 데이터베이스에서 실행하는 경우 아카이브를 선택하라는 메시지가 표시됩니다. 아카이브에서 실행하는 경우 데이터 배포기는 현재 데이터베이스로 시작됩니다.

## 설정
- 데이터베이스 서버, 데이터베이스 - 작업할 데이터베이스를 선택합니다
- 데이터 아카이브 - 비교 및 동기화에 사용할 데이터가 들어 있는 폴더를 선택합니다
### 테이블 관련
- 키(일치 열) - 데이터베이스와 아카이브 간에 행을 일치시키는 데 사용할 열을 선택합니다
### 복제기 설정
아래 설정("테이블" - 배포 및 전역 데이터 배포 설정)은 복제기에 특화된 설정이며 [데이터 복제기](data-replicator) 항목에서 설명합니다

## 데이터 차이점 복사
데이터 배포기는 아카이브의 데이터와 데이터베이스의 데이터 간 차이점을 보여줍니다. 차이가 있는 셀을 선택하면 해당 차이점을 아카이브 또는 데이터베이스에 기록할 수 있습니다. 이러한 셀이 선택되면 오른쪽 아래 모서리에 동기화를 수행할 수 있는 버튼이 나타납니다.
- x개 행, y개 열을 아카이브에 쓰기 - 선택한 셀을 데이터베이스에서 아카이브로 복사합니다.
- x개 행, y개 열을 데이터베이스에 쓰기 - 선택한 셀을 아카이브에서 데이터베이스로 복사합니다. 먼저 변경 SQL이 포함된 확인 대화 상자가 표시됩니다.

## 데이터 복제기 작업
- DB에 배포 - 구성된 설정으로 변경 사항을 데이터베이스에 배포하는 작업입니다
- 셸 생성 - 배포를 실행할 JavaScript 파일을 만드는 작업입니다. 이 파일은 명령줄에서 실행할 수 있습니다
- SQL 생성 - 아카이브의 변경 사항을 데이터베이스에 배포하는 SQL을 만듭니다

이러한 작업에 대한 자세한 내용은 [데이터 복제기](data-replicator) 항목을 참조하세요
