Coloque o DbGate em funcionamento e conecte-se ao seu primeiro banco de dados. O DbGate roda como aplicativo desktop no Windows, macOS e Linux, ou como aplicação web no Docker, NPM, AWS e Azure - assim você pode instalá-lo da maneira que melhor se encaixa no seu ambiente. Após a instalação, você cria uma conexão informando os dados do seu servidor (com túnel SSH e SSL opcionais), e o DbGate abre o banco de dados para navegação e consultas.

* [Instalação](installation) - instale o aplicativo desktop ou implante a versão web (Docker, NPM, AWS, Azure)
* [Conexão](connection) - adicione uma conexão, escolha um modo de senha e configure túnel SSH e SSL
