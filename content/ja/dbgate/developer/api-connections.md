DbGate は REST API、GraphQL サービス、OData エンドポイントへの接続をサポートしています。これらの API 接続はデータベース接続と同じインターフェースパターンを使用するため、API とデータベースを統一された環境で扱うことができます。

API 接続のサポートは DbGate Premium で利用できます。

> デスクトップアプリを使わずに API を参照したいですか？[DbGate Central](/dbgate-central/connecting-to-api-endpoints/) は GraphQL / oData / Shopify 接続の独立したホスト型実装であり、ブラウザー向けにゼロから再実装されています。

## GraphQL

GraphQL 接続を使用すると、GraphQL API を操作できます。DbGate はスキーマのイントロスペクションとクエリ実行の機能を提供します。

### GraphQL 接続の作成

GraphQL 接続を作成するには、新規接続ダイアログを使用し、接続タイプとして GraphQL を選択します。GraphQL エンドポイントの URL を入力し、必要に応じて認証を設定します。

### スキーマのイントロスペクション

DbGate は、利用可能な型、クエリ、ミューテーション、およびそれらの引数を含む GraphQL スキーマを自動的に検出します。スキーマブラウザーは型システムを表示し、API の構造を探索できるようにします。

### クエリエディター

GraphQL クエリエディターでは、クエリとミューテーションを記述できます。GraphQL エクスプローラーを使用して、スキーマからフィールドや引数を選択してクエリを組み立てることもできます。

![screenshot](https://media.dbgate.io/img/rest-graphql-query-light.png)

### 変数

GraphQL クエリは変数をサポートしています。変数パネルで変数を定義し、標準の GraphQL 変数構文を使用してクエリ内で参照します。変数はフォームで編集することも、生の JSON として編集することもできます。

### レスポンスビューアー

クエリ結果は、展開可能なツリー構造を持つ整形された JSON ビューアーで表示されます。レスポンス内に配列が検出された場合は、表形式のビューが自動的に表示されます。必要に応じて生の JSON ビューに戻すこともできます。

## OpenAPI (Swagger)

OpenAPI 接続は、OpenAPI 仕様 (バージョン 2.0 および 3.0) を提供する REST API をサポートします。

### OpenAPI 接続の作成

新規接続を作成し、接続タイプとして OpenAPI を選択します。OpenAPI 仕様ファイル (通常は swagger.json または openapi.json) の URL を指定します。DbGate は仕様を解析し、文書化されているすべてのエンドポイントを利用可能にします。

### API ドキュメントブラウザー

OpenAPI ブラウザーは、タグとパスごとに整理された利用可能なすべてのエンドポイントを表示します。各エンドポイントについて、次の情報を確認できます:
- HTTP メソッド (GET、POST、PUT、DELETE、PATCH)
- パラメーター (パス、クエリ、ヘッダー、ボディ)
- リクエストボディのスキーマ
- ドキュメントの説明

### リクエストの実行

エンドポイントを選択すると、リクエストビルダーが開きます。必要なパラメーター、ヘッダー、リクエストボディを入力します。リクエストを実行して API サーバーに送信します。

![screenshot](https://media.dbgate.io/img/rest-openapi-query-light.png)

### レスポンスの検査

レスポンスのステータスコード、ヘッダー、ボディを確認できます。JSON レスポンスは整形され、ツリービューとテーブルビューの両方で表示できます。JSON 以外のレスポンスはテキストとして表示されます。

## OData

OData 接続では、標準の OData クエリ構文を使用して OData サービスにクエリを実行できます。

### OData 接続の作成

接続タイプとして OData を選択し、新規接続を作成します。OData サービスのルート URL を入力します。DbGate はサービスのメタデータドキュメントを取得します。

### メタデータの探索

メタデータブラウザーには、サービスメタデータで定義されている利用可能なエンティティセット、エンティティ型、プロパティ、リレーションシップが表示されます。

### クエリの実行

OData クエリは標準の OData クエリオプションをサポートしています:
- `$filter` - プロパティ値によるエンティティのフィルタリング
- `$select` - 返却するプロパティの指定
- `$expand` - 関連エンティティの取り込み
- `$orderby` - 結果の並べ替え
- `$top` および `$skip` - ページング
- `$count` - 結果件数の取得

![screenshot](https://media.dbgate.io/img/rest-odata-query-light.png)

結果は、データベースのクエリ結果と同様に表形式で表示されます。

## 認証

すべての API 接続タイプは複数の認証方式をサポートしています:

- **API キー** - キー名と値を指定し、ヘッダーまたはクエリパラメーターとして送信します
- **Bearer トークン** - Authorization ヘッダーで送信される OAuth または JWT トークン
- **Basic 認証** - HTTP Basic 認証を使用したユーザー名とパスワード
- **認証なし** - 公開 API 向け

認証は接続のプロパティで設定します。

## データのエクスポート

API のレスポンスデータは、DbGate の標準のエクスポート機能を使用してさまざまな形式にエクスポートできます:
- JSON
- CSV
- Excel
- SQL INSERT 文
- XML

表形式のデータブラウザーで、標準の「エクスポート」コンテキストメニュー項目を使用します。

## 複数の API の利用

複数の API やデータベースへの接続を作成できます。複数のリクエストタブを開いて、異なるエンドポイントを同時に扱うことができます。

タブの状態はアプリを閉じて再度開いた後も保持され、閉じたタブの履歴からリクエストを再度開くことができます。
