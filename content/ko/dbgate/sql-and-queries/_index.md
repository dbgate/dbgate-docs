원하는 방식으로 데이터를 조회하세요. 서식 지정, 코드 자동 완성, 편집 가능한 결과를 갖춘 완전한 기능의 편집기에서 SQL을 직접 작성하거나, 쿼리 디자이너로 SQL 지식 없이도 쿼리를 시각적으로 구성할 수 있습니다. 여기에 ER 다이어그램이 더해져 테이블 간의 관계를 보여 주므로, 쿼리하기 전에 데이터베이스를 이해할 수 있습니다.

* [SQL 편집기](sql-editor) - 스크립트 실행, SQL 서식 지정 및 자동 완성, 쿼리 결과 편집
* [쿼리 디자이너](query-designer) - 코드 작성 없이 시각적으로 SQL 구성
* [ER 다이어그램](er-diagrams) - 테이블 관계와 데이터베이스 구조 시각화
