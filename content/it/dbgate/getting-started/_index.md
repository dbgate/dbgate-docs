Configura DbGate e connettiti al tuo primo database. DbGate funziona come applicazione desktop su Windows, macOS e Linux, oppure come applicazione web in Docker, NPM, AWS e Azure - in questo modo puoi installarlo nel modo più adatto alla tua configurazione. Una volta installato, crei una connessione inserendo i dettagli del server (con tunnel SSH e SSL opzionali) e DbGate apre il database per la navigazione e l'esecuzione di query.

* [Installazione](installation) - installa l'applicazione desktop o distribuisci la versione web (Docker, NPM, AWS, Azure)
* [Connessione](connection) - aggiungi una connessione, scegli una modalità di password e configura il tunnel SSH e SSL
