아카이브는 JSONL(NDJSON) 형식의 데이터를 담고 있는 폴더입니다. DbGate에서는 아카이브를 매우 효율적으로 다룰 수 있으며, 데이터베이스로 가져오거나, 다른 형식으로 내보내거나, 아카이브 안의 데이터를 직접 편집할 수 있습니다. 아카이브는 로컬 파일에 저장된 매우 빠르고 가벼운 데이터베이스처럼 동작합니다.

## JSONL 형식
DbGate는 내부적으로 모든 곳에서 JSONL 형식을 사용합니다. JSONL은 각 줄에 JSON 문자열로 변환된 행이 들어 있는 텍스트 파일입니다. DbGate는 첫 번째 줄에 테이블 구조를 담은 헤더(역시 JSON 형식)가 포함될 수 있다고 가정합니다. 고정된 첫 줄 없이 동적 구조로 JSONL을 사용하는 경우, 이 형식은 표준화되어 있어 다른 여러 도구에서도 불러올 수 있습니다.

## 아카이브 폴더
아카이브는 JSONL 파일이 들어 있는 폴더로 구성되며, 데이터베이스와 유사한 구조를 가집니다. 따라서 데이터베이스 전체를 새 아카이브로 내보낼 수 있습니다. 모든 테이블이 하나의 JSON 파일로 내보내지며, 헤더 줄 덕분에 테이블 구조도 함께 보존됩니다.

## 아카이브 파일 보기 및 편집
JSONL 파일은 여러 가지 모드로 열 수 있습니다.
- 컨텍스트 메뉴 "Open" - 데이터 그리드를 열어 JSONL 데이터를 정렬, 필터링하고 편집할 수 있습니다
- 컨텍스트 메뉴 "Open in text editor" - JSONL 파일을 직접 수동으로 편집할 수 있습니다

## 아카이브와 DB 모델
아카이브 폴더는 DB 모델의 저장소로도 사용됩니다. 데이터베이스 컨텍스트 메뉴의 "Export DB model"을 사용해 DB 모델을 내보낼 수 있습니다. 그런 다음 이 모델을 편집하고(테이블 구조는 YAML 파일, 뷰와 저장 프로시저는 SQL 파일), 실제 데이터베이스와 비교한 뒤 데이터베이스에 배포할 수 있습니다
