DbGate 可以比较数据库结构并部署更改 *(Premium)*。这对于保持各环境之间的同步以及对架构进行版本控制非常有用。

![Compare database](https://media.dbgate.io/img/compare-database-settings-light.png)

## 比较数据库

* **比较两个数据库** - 查找列、视图定义和其他 SQL 对象中的差异。
* **同步结构** - 生成并执行使一个数据库与另一个数据库保持一致所需的操作。
* **与 YAML 模型比较** - 将真实数据库与存储在 YAML 中的模型进行比较，并部署差异。
* **设置** - 控制比较过程，例如忽略外键、排除特定对象或选择要执行的同步操作。

## 导出数据库模型

* **生成到文件夹** - 将现有数据库的模型保存到文件夹，或保存到单个 JSON 文件。
* **YAML 表文件** - 表以简单的 YAML 文件形式存储，你可以将其保存在 Git 仓库中。
* **SQL 定义文件** - 视图、存储过程和函数以 SQL 文件形式存储。

## 部署

使用比较工具以可视化方式部署模型，或者从命令行部署，作为 CI/CD 流水线的一部分。有关模型文件格式和 CLI 工作流程，请参阅[数据库部署](dbdeploy)。
