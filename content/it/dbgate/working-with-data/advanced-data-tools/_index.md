DbGate offre diversi strumenti avanzati per i dati, adatti a scenari specifici:

- [Archivi di dati](archives) - dati delle tabelle memorizzati in cartelle (in formato NDJSON) sul tuo computer locale. Puoi sfogliare e modificare questi dati in modo simile alla consultazione delle tabelle nel database
- [Data deployer](data-deployer) - confronta e sincronizza visivamente i dati tra un archivio di dati e un database reale
- [Data replicator](data-replicator) - replica i tuoi dati da un archivio di dati a un database, adatto all'esecuzione dall'app DbGate o dalla riga di comando
