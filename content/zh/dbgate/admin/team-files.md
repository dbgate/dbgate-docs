团队文件是存储在 DbGate 内部存储中的 SQL、图表或其他文件。桌面版 DbGate 将文件存储在用户文件夹中，Team 版允许以同样的方式存储文件（在 docker 卷中），但更合适的做法是将文件存储在存储数据库中，这样在重新创建 DbGate 容器时文件不会被重新创建。

- 磁盘文件
    - 存储在磁盘或 docker 卷上的文件
    - 除非您显式定义 docker 卷（例如在 docker-compose.yaml 中），否则在重新创建容器时文件会被重新创建。
- 团队文件
    - 存储在存储数据库中的文件
    - 在重新创建容器时不会丢失，无需定义 docker 卷
    - 允许为用户和角色定义细粒度的访问权限

## 将 SQL 文件保存为团队文件
保存 SQL 文件时，只需勾选“保存到团队文件夹”复选框。该文件将被保存为团队文件。
