Interrogez vos données comme bon vous semble. Écrivez du SQL directement dans un éditeur complet offrant le formatage, la complétion de code et des résultats modifiables, ou construisez vos requêtes visuellement avec le concepteur de requêtes - aucune connaissance de SQL requise. Les diagrammes ER complètent le tout en montrant comment vos tables sont liées entre elles, afin que vous puissiez comprendre la base de données avant de l'interroger.

* [Éditeur SQL](sql-editor) - exécutez des scripts, formatez et complétez le SQL, modifiez les résultats des requêtes
* [Concepteur de requêtes](query-designer) - construisez du SQL visuellement, sans écrire de code
* [Diagrammes ER](er-diagrams) - visualisez les relations entre les tables et la structure de la base de données
