Trabaje sobre la estructura de sus bases de datos en lugar de sobre los datos que contienen. Diseñe tablas, claves e índices mediante la interfaz gráfica con una vista previa del SQL antes de aplicar nada, compare dos bases de datos (o una base de datos con un modelo YAML) y sincronice las diferencias, e implemente modelos de forma visual o desde la línea de comandos como parte de un pipeline de CI/CD. Esta sección también cubre la copia de seguridad y la restauración nativas.

* [Editor de tablas y esquemas](schema-editor) - cree y modifique tablas, claves e índices mediante la interfaz gráfica
* [Implementación de base de datos](dbdeploy) - archivos de modelo YAML/SQL e implementación desde la CLI
* [Comparar e implementar modelos](model-compare-deploy) - compare la estructura y sincronice bases de datos *(Premium)*
* [Copia de seguridad y restauración](backup-restore) - copia de seguridad y restauración nativas de bases de datos
