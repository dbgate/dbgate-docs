DbGate 可以通过图形界面创建和修改数据库结构，无需手动编写 DDL。从表的上下文菜单（“编辑表”）中打开其结构编辑器，或从数据库上下文菜单中创建新表。

![Table structure editor](https://media.dbgate.io/img/table-structure-editor-light.png)

## 编辑表

* **列与数据类型** - 为新表或现有表定义列、数据类型、是否可为空以及默认值。
* **键与索引** - 管理主键、外键和索引。
* **引擎特定属性** - 设置数据库特定的选项，例如 MySQL 的表引擎。

## SQL 预览与安全变更

* **SQL 预览** - 在保存任何内容之前，DbGate 会显示生成的 SQL，供你审阅。
* **表重建警告** - 当某项变更需要重建表时（这是某些数据库的限制），DbGate 会向你发出警告，并让你先检查生成的脚本。

## 其他数据库对象

你还可以创建、删除和修改其他对象 - 视图、存储过程和函数 - 并从对象树中浏览表、视图、过程、函数和 MongoDB 集合。
