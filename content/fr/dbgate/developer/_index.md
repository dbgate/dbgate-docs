Allez au-delà de l'interface graphique et mettez DbGate au service de vos propres outils et pipelines. Automatisez les exports, les imports et les déploiements avec du JavaScript qui s'exécute dans l'application ou en ligne de commande, interrogez des points de terminaison GraphQL/OData/OpenAPI comme s'il s'agissait de bases de données, et étendez DbGate avec vos propres plugins pour les pilotes de bases de données ou les formats de fichiers. Cette section documente également l'API de scripting et le front matter SQL utilisé par la base de connaissances.

* [Connexions API](api-connections) - parcourir et interroger des points de terminaison REST GraphQL, OData et OpenAPI
* [Documentation de l'API](apidoc) - référence de l'API de scripting de DbGate
* [Développement de plugins](plugin-development) - créer des plugins pour les moteurs de bases de données et les formats de fichiers
* [Scripting](scripting) - automatiser des tâches avec JavaScript, dans l'application ou en ligne de commande
* [Front Matter SQL](sql-front-matter) - annoter les scripts SQL pour la base de connaissances et les graphiques
