DbGate 提供多种产品，分别适用于不同的数据工作方式。请通过本页面找到适合您的产品。

| 产品 | 托管方式 | 登录 | 最适合 |
|---|---|---|---|
| [DbGate](/zh/dbgate/)（Community / Premium / Team Premium） | 桌面应用，或自托管 Web（Docker、NPM、AWS、Azure） | 可选（Team Premium） | 功能齐全的 SQL 和 NoSQL 数据库服务器客户端，配备 [DbGate Cloud](/zh/dbgate/dbgate-cloud/) 在线存储，用于保存连接和脚本 |
| [DbGate Central](/zh/dbgate-central/) | 托管、付费、浏览器内运行 | 必需 | 像操作数据库一样浏览、查询和编辑 GraphQL、oData 和 Shopify API，并提供 BI 报表和面向 AI 智能体的 MCP 服务器 |
| [DbGate Shopify App](/zh/dbgate-shopify-app/) | 原生 Shopify 应用，嵌入到您的店铺管理后台 | Shopify 会话 | 批量查看/编辑 Shopify 店铺数据，并生成定时商品数据源 |
| [DbGate Lite](/zh/dbgate-lite/) | 托管、免费、浏览器内运行 | 无 | 学习 SQL 以及对数据文件进行快速的临时性处理 |

DbGate Lite 和 DbGate Central 基于相同的底层网格和查询引擎构建 —— 因此两者在筛选、编辑和浏览方面的体验完全一致，但 Lite 是免费的，且仅支持本地 SQLite/DuckDB 数据库和文件，而 Central 则增加了托管 API 连接、云端存储的工作区以及团队协作功能。
