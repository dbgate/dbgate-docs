O DbGate oferece diversas ferramentas avançadas de dados adequadas para cenários específicos:

- [Arquivos de dados](archives) - dados de tabelas armazenados em pastas (no formato NDJSON) no seu computador local. Você pode navegar e editar esses dados da mesma forma que navega pelas tabelas do banco de dados
- [Implantador de dados](data-deployer) - compare e sincronize visualmente os dados entre um arquivo de dados e um banco de dados real
- [Replicador de dados](data-replicator) - replique seus dados de um arquivo de dados para o banco de dados, adequado para execução no aplicativo DbGate ou pela linha de comando
