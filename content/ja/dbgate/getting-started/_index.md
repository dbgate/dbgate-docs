DbGate をセットアップして最初のデータベースに接続しましょう。DbGate は Windows、macOS、Linux 上でデスクトップアプリケーションとして、あるいは Docker、NPM、AWS、Azure 上で Web アプリケーションとして動作するため、ご自身の環境に合った方法でインストールできます。インストール後は、サーバーの情報（必要に応じて SSH トンネルや SSL も）を入力して接続を作成すると、DbGate がデータベースを開き、参照やクエリの実行ができるようになります。

* [インストール](installation) - デスクトップアプリのインストール、または Web 版のデプロイ（Docker、NPM、AWS、Azure）
* [接続](connection) - 接続の追加、パスワードモードの選択、SSH トンネルと SSL の設定
