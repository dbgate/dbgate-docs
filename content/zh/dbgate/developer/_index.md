超越图形界面，让 DbGate 融入你自己的工具和流水线。使用可在应用内或命令行中运行的 JavaScript 自动执行导出、导入和部署，像查询数据库一样查询 GraphQL/OData/OpenAPI 端点，并通过你自己的插件扩展 DbGate 以支持数据库驱动或文件格式。本节还介绍了脚本 API 以及知识库所使用的 SQL front matter。

* [API 连接](api-connections) - 浏览和查询 GraphQL、OData 和 OpenAPI REST 端点
* [API 文档](apidoc) - DbGate 脚本 API 参考
* [插件开发](plugin-development) - 为数据库引擎和文件格式构建插件
* [脚本](scripting) - 在应用内或命令行中使用 JavaScript 自动执行任务
* [SQL Front Matter](sql-front-matter) - 为知识库和图表标注 SQL 脚本
