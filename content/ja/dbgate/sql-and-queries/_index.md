自分に合った方法でデータを照会できます。フォーマット、コード補完、編集可能な結果を備えた本格的なエディターで直接 SQL を記述することも、クエリデザイナーでビジュアルにクエリを組み立てることもできます（SQL の知識は不要です）。ER 図はテーブル同士の関連を示してくれるので、クエリを実行する前にデータベースを理解できます。

* [SQL エディター](sql-editor) - スクリプトの実行、SQL のフォーマットと補完、クエリ結果の編集
* [クエリデザイナー](query-designer) - コードを書かずにビジュアルに SQL を構築する
* [ER 図](er-diagrams) - テーブルの関連とデータベース構造を視覚化する
