Consulte seus dados da maneira que preferir. Escreva SQL diretamente em um editor completo, com formatação, autocompletar de código e resultados editáveis, ou construa consultas visualmente com o designer de consultas - sem necessidade de conhecer SQL. Os diagramas ER completam o conjunto mostrando como suas tabelas se relacionam, para que você possa entender o banco de dados antes de consultá-lo.

* [Editor SQL](sql-editor) - execute scripts, formate e complete SQL, edite os resultados das consultas
* [Designer de consultas](query-designer) - construa SQL visualmente, sem escrever código
* [Diagramas ER](er-diagrams) - visualize relações entre tabelas e a estrutura do banco de dados
