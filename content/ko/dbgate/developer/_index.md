GUI를 넘어 DbGate를 여러분의 도구와 파이프라인에서 활용해 보세요. 앱 내에서 또는 명령줄에서 실행되는 JavaScript로 내보내기, 가져오기, 배포를 자동화하고, GraphQL/OData/OpenAPI 엔드포인트를 데이터베이스처럼 쿼리하며, 데이터베이스 드라이버나 파일 형식을 위한 자체 플러그인으로 DbGate를 확장할 수 있습니다. 이 섹션에서는 스크립팅 API와 지식 베이스에서 사용되는 SQL front matter도 함께 설명합니다.

* [API 연결](api-connections) - GraphQL, OData 및 OpenAPI REST 엔드포인트 탐색 및 쿼리
* [API 문서](apidoc) - DbGate 스크립팅 API 레퍼런스
* [플러그인 개발](plugin-development) - 데이터베이스 엔진 및 파일 형식용 플러그인 개발
* [스크립팅](scripting) - 앱 내에서 또는 명령줄에서 JavaScript로 작업 자동화
* [SQL Front Matter](sql-front-matter) - 지식 베이스와 차트를 위한 SQL 스크립트 주석 추가
