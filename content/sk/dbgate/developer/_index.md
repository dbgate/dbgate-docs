Prekročte hranice grafického rozhrania a zapojte DbGate do vlastných nástrojov a pipeline. Automatizujte exporty, importy a nasadenia pomocou JavaScriptu, ktorý beží v aplikácii alebo z príkazového riadka, dopytujte sa na koncové body GraphQL/OData/OpenAPI, akoby to boli databázy, a rozšírte DbGate o vlastné pluginy pre databázové ovládače alebo formáty súborov. Táto sekcia zároveň dokumentuje skriptovacie API a SQL front matter používaný v znalostnej báze.

* [API pripojenia](api-connections) - prehliadanie a dopytovanie koncových bodov GraphQL, OData a OpenAPI REST
* [Dokumentácia API](apidoc) - referenčná príručka pre skriptovacie API DbGate
* [Vývoj pluginov](plugin-development) - tvorba pluginov pre databázové enginy a formáty súborov
* [Skriptovanie](scripting) - automatizácia úloh pomocou JavaScriptu, v aplikácii alebo z príkazového riadka
* [SQL Front Matter](sql-front-matter) - anotovanie SQL skriptov pre znalostnú bázu a grafy
