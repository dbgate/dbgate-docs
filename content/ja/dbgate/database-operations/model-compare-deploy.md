DbGate はデータベース構造を比較し、変更をデプロイできます *(Premium)*。これは環境間の同期を保つ場合や、スキーマをバージョン管理する場合に便利です。

![Compare database](https://media.dbgate.io/img/compare-database-settings-light.png)

## データベースの比較

* **2 つのデータベースを比較** - カラム、ビュー定義、その他の SQL オブジェクトの差分を見つけます。
* **構造の同期** - 一方のデータベースを他方に一致させるために必要なアクションを生成して実行します。
* **YAML モデルとの比較** - 実際のデータベースを YAML に保存されたモデルと比較し、差分をデプロイします。
* **設定** - 比較を制御します。たとえば、外部キーを無視する、特定のオブジェクトを除外する、実行する同期アクションを選択するなどです。

## データベースモデルのエクスポート

* **フォルダーへのスキャフォールド** - 既存のデータベースのモデルをフォルダーに、または単一の JSON ファイルに保存します。
* **YAML テーブルファイル** - テーブルはシンプルな YAML ファイルとして保存され、Git リポジトリで管理できます。
* **SQL 定義ファイル** - ビュー、ストアドプロシージャ、関数は SQL ファイルとして保存されます。

## デプロイ

Compare ツールで視覚的にモデルをデプロイすることも、CI/CD パイプラインの一部としてコマンドラインからデプロイすることもできます。モデルファイルの形式と CLI のワークフローについては、[データベースデプロイ](dbdeploy) を参照してください。
