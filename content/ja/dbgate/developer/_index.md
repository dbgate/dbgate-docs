GUI の枠を超えて、DbGate を自分のツールやパイプラインに組み込んで活用しましょう。アプリ内またはコマンドラインから実行される JavaScript でエクスポート、インポート、デプロイを自動化し、GraphQL / OData / OpenAPI エンドポイントをデータベースのようにクエリし、データベースドライバーやファイル形式に対応した独自のプラグインで DbGate を拡張できます。このセクションでは、スクリプティング API と、ナレッジベースで使用される SQL フロントマターについても説明します。

* [API 接続](api-connections) - GraphQL、OData、OpenAPI REST エンドポイントの参照とクエリ
* [API ドキュメント](apidoc) - DbGate スクリプティング API のリファレンス
* [プラグイン開発](plugin-development) - データベースエンジンやファイル形式向けのプラグインを作成する
* [スクリプティング](scripting) - アプリ内またはコマンドラインから JavaScript でタスクを自動化する
* [SQL フロントマター](sql-front-matter) - ナレッジベースやチャート向けに SQL スクリプトへ注釈を付ける
