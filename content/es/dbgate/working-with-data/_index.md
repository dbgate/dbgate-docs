Todo lo que haces con las filas reales de tu base de datos está aquí. Explora y edita los datos de las tablas en una cuadrícula rápida al estilo de Excel, acótalos con filtros potentes y navega entre tablas relacionadas mediante claves foráneas y vistas maestro/detalle. Cuando necesites algo más que una cuadrícula, convierte los resultados en gráficos o mapas, consulta el chat de base de datos con IA, mueve datos con exportación/importación o guarda archivos NDJSON locales de ellos.

* [Explorador y editor de datos](data-browser) - la vista de cuadrícula, la edición en línea y la navegación por datos relacionados
* [Filtrado de datos](data-filtering) - sintaxis de las expresiones de filtro
* [Exportación e importación](export-import) - mueve datos dentro y fuera de las tablas
* [Gráficos](charts) - visualiza los resultados de las consultas
* [Mapas](maps) - muestra datos GEO en un mapa
* [Perspectivas](perspectives) - vistas anidadas de solo lectura sobre datos relacionados complejos
* [Funciones de IA](ai-features) - chat de base de datos, asistente SQL y explicación de errores *(Premium)*
* [Herramientas de datos avanzadas](advanced-data-tools) - archivos, desplegador de datos y replicador de datos
