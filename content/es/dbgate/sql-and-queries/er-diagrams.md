Los diagramas ER (entidad-relación) visualizan tus tablas y las relaciones entre ellas. Genera un diagrama para toda la base de datos o para un conjunto de tablas seleccionado.

![Diagrama ER](https://media.dbgate.io/img/database-diagram-light.png)

## Crear un diagrama

* Muestra las relaciones de una sola tabla o la estructura de toda la base de datos.
* Añade tablas a un diagrama existente desde el árbol de objetos de la base de datos.

## Personalizar el diagrama *(la configuración avanzada es Premium)*

* **Colores y grupos** - cambia el color de una tabla y define grupos lógicos de tablas.
* **Elegir columnas** - muestra todas las columnas, solo las columnas not-null o solo las columnas de clave primaria.
* **Atributos** - configura si se muestran los tipos de datos y los indicadores NULL/NOT NULL.

## Exportación

Exporta el diagrama a una página HTML sencilla y autocontenida para compartirlo o incluirlo en la documentación.

Los diagramas se almacenan como el resto de objetos de DbGate y se pueden compartir a través de carpetas de [DbGate Cloud](/es/dbgate/dbgate-cloud/).
