Ve más allá de la interfaz gráfica y pon DbGate a trabajar en tus propias herramientas y flujos de trabajo. Automatiza exportaciones, importaciones e implementaciones con JavaScript que se ejecuta en la aplicación o desde la línea de comandos, consulta endpoints GraphQL/OData/OpenAPI como si fueran bases de datos y amplía DbGate con tus propios plugins para controladores de bases de datos o formatos de archivo. Esta sección también documenta la API de scripting y el front matter SQL utilizado por la base de conocimiento.

* [Conexiones API](api-connections) - explora y consulta endpoints REST de GraphQL, OData y OpenAPI
* [Documentación de la API](apidoc) - referencia de la API de scripting de DbGate
* [Desarrollo de plugins](plugin-development) - crea plugins para motores de bases de datos y formatos de archivo
* [Scripting](scripting) - automatiza tareas con JavaScript, en la aplicación o desde la línea de comandos
* [SQL Front Matter](sql-front-matter) - anota scripts SQL para la base de conocimiento y los gráficos
