## Aba Conexões
Configure as conexões disponíveis no DbGate. As conexões devem estar mapeadas para usuários ou funções para ficarem disponíveis.

![Administração de conexões - DbGate](https://media.dbgate.io/img/connection-administration-light.png)

## Acesso direto ao banco de dados de armazenamento
O usuário administrador também tem acesso ao banco de dados de armazenamento interno, portanto você pode realizar operações diretamente no banco de dados (por exemplo, exportações/importações de usuários etc.). Essa permissão também pode ser concedida a qualquer outro usuário, por meio da permissão "Interal storage"
