## Registerkarte "Verbindungen"
Konfigurieren Sie die in DbGate verfügbaren Verbindungen. Verbindungen müssen Benutzern oder Rollen zugeordnet werden, damit sie verfügbar sind.

![Verwaltung der Verbindungen - DbGate](https://media.dbgate.io/img/connection-administration-light.png)

## Direkter Zugriff auf die Speicherdatenbank
Der Admin-Benutzer hat auch Zugriff auf die interne Speicherdatenbank, sodass Sie Operationen direkt auf der Datenbank ausführen können (z. B. Exporte/Importe von Benutzern usw.). Diese Berechtigung kann auch jedem anderen Benutzer erteilt werden, Berechtigung "Interal storage"
