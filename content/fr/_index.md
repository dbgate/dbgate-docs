DbGate est disponible en plusieurs produits, conçus pour différentes façons de travailler avec les données. Utilisez cette page pour trouver celui qui vous convient.

| Produit | Hébergement | Connexion | Idéal pour |
|---|---|---|---|
| [DbGate](/fr/dbgate/) (Community / Premium / Team Premium) | Application de bureau, ou web auto-hébergé (Docker, NPM, AWS, Azure) | Facultative (Team Premium) | Client complet pour les serveurs de bases de données SQL et NoSQL, avec le stockage en ligne [DbGate Cloud](/fr/dbgate/dbgate-cloud/) pour les connexions et les scripts |
| [DbGate Central](/fr/dbgate-central/) | Hébergé, payant, dans le navigateur | Requise | Parcourir, interroger et modifier les API GraphQL, oData et Shopify comme une base de données, avec des rapports BI et un serveur MCP pour les agents IA |
| [DbGate Shopify App](/fr/dbgate-shopify-app/) | Application Shopify native, intégrée à l'administration de votre boutique | Session Shopify | Consultation et modification en masse des données de votre boutique Shopify et génération de flux de produits planifiés |
| [DbGate Lite](/fr/dbgate-lite/) | Hébergé, gratuit, dans le navigateur | Aucune | Apprendre le SQL et travailler rapidement et ponctuellement avec des fichiers de données |

DbGate Lite et DbGate Central reposent sur la même grille et le même moteur de requêtes sous-jacents - le filtrage, l'édition et la navigation sont donc identiques dans les deux, mais Lite est gratuit et fonctionne uniquement avec des bases de données et fichiers SQLite/DuckDB locaux, tandis que Central ajoute les connexions API hébergées, les espaces de travail stockés dans le cloud et les fonctionnalités d'équipe.
