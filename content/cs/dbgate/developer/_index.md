Překročte hranice grafického rozhraní a zapojte DbGate do svých vlastních nástrojů a pipeline. Automatizujte exporty, importy a nasazení pomocí JavaScriptu, který běží v aplikaci nebo z příkazové řádky, dotazujte se na koncové body GraphQL/OData/OpenAPI, jako by šlo o databáze, a rozšiřte DbGate o vlastní pluginy pro databázové ovladače nebo formáty souborů. Tato sekce také dokumentuje skriptovací API a SQL front matter používaný znalostní bází.

* [API připojení](api-connections) - procházení a dotazování koncových bodů GraphQL, OData a OpenAPI REST
* [Dokumentace API](apidoc) - referenční příručka ke skriptovacímu API DbGate
* [Vývoj pluginů](plugin-development) - tvorba pluginů pro databázové enginy a formáty souborů
* [Skriptování](scripting) - automatizace úloh pomocí JavaScriptu, v aplikaci nebo z příkazové řádky
* [SQL Front Matter](sql-front-matter) - anotace SQL skriptů pro znalostní bázi a grafy
